# 教培 CRM 系统原型

使用 HTML、CSS 和原生 JavaScript 实现的教培业务交互原型，包含线索管理、跟进沟通、报名选班、收费订单、预约试听和教务管理等功能。

## 本地预览

使用浏览器打开项目根目录的 `index.html`。

## 项目说明

- `index.html`：页面入口。
- 根目录中的 JavaScript 和 CSS：业务交互及页面样式。
- `templates/`：导入模板。
- `tests/`：基于 Node.js 的功能检查脚本。

这是交互原型。已保存的业务数据和业务附件使用当前浏览器的 IndexedDB 保存；表单、微信活码和商城装修沿用各自的本机存储。刷新页面后保留已保存内容，页面右下角显示业务数据保存状态。未提交的编辑草稿不作为已保存业务记录。

本机数据不会自动同步到其他设备或浏览器。请保持使用同一浏览器和打开地址；直接打开文件与 HTTP 地址的存储彼此独立。清除浏览器站点数据会清除本机记录。多个页面同时修改时，过期页面会提示冲突，避免覆盖另一页的新记录。

支付、电话、企微、短信、AI 识别等真实服务需要另外接入；本机保存不等同于服务端备份。财务中心的“收款设置”按要求保留入口，等待后续设计。

- 单个报名手选“续费”时须关联原班；批量续费只在存在唯一的同学科、更早学期原班时导入，否则提示改用单个报名核对。
